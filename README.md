## 🧠 Overview

VOID_DECK is a Python-based command-line tool designed to simulate a “cyberdeck” experience while providing functional encryption and data handling capabilities.

It blends:
- Practical encryption workflows
- File handling utilities
- Thematic UI/UX inspired by cyberpunk media

---

## 🚀 Features

### 🔐 Matrix Encryption (Text)
- XOR-based encryption using seeded PRNG
- HEX output for portability
- Integrity verification (CRC32 + timestamp + operator tag)
- Clipboard integration

---

### 📦 Black Box (File Encryption)
- Encrypt/decrypt **any file type**
- Outputs `.ghost` files
- Integrity verification for tamper detection

---

### 🖼️ Phantom Image Steganography
- Hide encrypted payloads inside `.jpg` / `.png`
- Extract hidden data with correct key
- Lightweight concealment method

---

### 🧪 Duress Protocol (⚠️ Unique Feature)
- Enter `cleansweep` as the key
- Returns a **fake decrypted output**
- Designed for plausible deniability scenarios
